📖 Giải thích quy trình nhập liệu & quản lý kế hoạch

1. Setup ban đầu — Master Data

Trước khi sinh kế hoạch, hệ thống cần 2 nguồn dữ liệu gốc:

📍 Ubicacion (điểm bán)
  • BR, BC, Distrito, Tipo (Mercado/BTS/Rural/...)
  • Prioridad: 1 = cao nhất, 2 = thứ 2, ...
  • Lịch traffic: WEEKDAY / WEEKEND / MONDAY..SUNDAY
  • Toạ độ GPS
  • Meta/Gasto/Merch mặc định (sẽ kế thừa cho campaign)
👥 PR / Grupo (nhân lực)
  • PR Code (mã promoter), BC, Grupo
  • Tipo: Exclusive / Part-time / Nuevo
  • Leader (AF/BC)
  • KPI Trabajo, Cantidad ngày làm/tháng
  • Estado: OK / NO OK

💡 Có thể nhập tay từng dòng, bulk editor, hoặc Import từ file Excel mẫu.

2. Sinh kế hoạch tháng — Plan Generator

  1. Chọn năm + tháng (vd. 2026/05).
  2. Tick "Xoá DRAFT cũ" (giữ PLANNED/RUNNING/DONE).
  3. Bấm 🚀 Sinh kế hoạch.
  4. Hệ thống chạy 4 pass theo thứ tự ưu tiên:
    PassTiêu chíMục đích
    1cùng BC + đúng lịch trafficTối ưu
    2khác BC + đúng lịch trafficBù thiếu nhân lực BC
    3cùng BC + ngoài lịch trafficĐủ cantidad_dia
    4chưa có PRSlot trống để gán tay
  5. Mỗi vòng: ưu tiên Ubic có prioridad thấp nhất trước.
  6. Chọn PR có capacity cao nhất để cân bằng tải.
  7. Ràng buộc: 1 PR ≤ 1 ca/ngày, 1 Ubic ≤ 1 campaign/ngày, không vượt cantidad_dia_trabajo.

⚠️ Tất cả campaign sinh ra là DRAFT — chưa có hiệu lực cho đến khi duyệt.

3. Duyệt & phân công — Campaigns page

BC/Manager mở trang Campaigns để review:

  • Kanban: nhìn nhanh phân bố trạng thái — kéo điều phối tâm lý.
  • List: xem chi tiết, filter theo BC/ngày/status.
  • Calendar: pivot vị trí × ngày, dễ phát hiện trùng/thiếu.
  • Chi tiết: chỉnh PR, ghi chú, đổi trạng thái thủ công.

Nếu mọi thứ OK, bấm ✅ Duyệt toàn bộ DRAFT → PLANNED bên Plan Generator để chốt lịch tháng trong 1 click.

4. Triển khai hằng ngày

  1. Sáng: BC/Leader vào Campaigns → Chi tiết, chuyển các campaign hôm nay từ PLANNED → RUNNING.
  2. PR đi điểm bán, làm theo Meta của campaign.
  3. Có sự cố? Đổi sang CANCELLED với ghi chú lý do.

5. Đóng campaign — Resultados

Cuối ngày, nhập kết quả thực tế:

  • Mở trang Resultados → chọn campaign hôm nay.
  • Nhập Resultado cho từng metric (so sánh với Meta).
  • Tick Checklist: Evidencia pago, Merch entregado, Activaciones, Digital, Campaña OK.
  • Ghi DF/BTS Code + Nota.
  • Bấm 🏁 Lưu & chuyển sang DONE.

Mọi thay đổi đều được lưu vào campaign_log để truy vết sau này.

6. Theo dõi tổng thể — Dashboard

  • Funnel trạng thái: bao nhiêu DRAFT/PLANNED/DONE — biết tiến độ tháng.
  • Meta vs Resultado: % đạt theo metric (so sánh BC).
  • Chi phí kế hoạch theo BC: stacked bar.
  • Tải PR: ai đang quá tải / dư thời gian.
  • Bản đồ: phân bố địa lý của campaign.

7. Import / Export

  • Import: upload file Excel có 2 sheet Ubicacion + PR Grupo giống mẫu — hệ thống parse và lưu vào DB (upsert).
  • Export: chọn tháng → tải Excel gồm Campaigns, Calendar (pivot), Results, và master data.
